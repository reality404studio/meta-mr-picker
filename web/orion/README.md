# ORION web (mac side)

three.js editor + loader for the ORION word, and the local relay server that talks to the Quest app.
Pure three.js 0.170.0 vendored in `vendor/three/` (import map, no bundler, no CDN). Zero npm dependencies.

## Run

```sh
cd unity/mood-picker/web/orion
node server/server.mjs                # http://localhost:5180  (--port, --dir ./inbox, --samples <dir>, --host)
```

- `/?mode=editor` — Before scene: clay ORION, TRACKING / THICKNESS / ROTATION sliders, material presets (sample chips + CLAY). Slider values go to the Quest over WebSocket.
- `/?mode=hero` — Throw Back scene: shows the last uploaded export, spins slowly (`&spin=0` to freeze), loader line, `DOWNLOAD GLB`, `OUTLINE` toggle.
- `/?mode=look` — same materials, static camera, no UI. Used for the Unity vs web look comparison.
- `?doc=<url>` loads a specific `orion.export.json` in any mode.

Local development server only: no auth, binds `0.0.0.0`, prints its LAN address. The Quest uses plain `ws://` and `http://`, so the Unity side needs Android cleartext traffic enabled (handled by card `build-a3a1-build-c0c8`).

## Protocol

WebSocket `/ws`. First message: `{"type":"hello","role":"mac"|"quest"}`. Messages are relayed to the opposite role.

| message | direction | note |
| --- | --- | --- |
| `{type:"slider", key, value}` | mac → quest | last value per key is replayed to new connections |
| `{type:"pullout", t}` | quest → mac | editor hides the 2D word |
| `{type:"export", path, url}` | server → mac | emitted after a `.json` upload; hero fetches `url` |
| `{type:"peer", role, online}` | server → both | connection status dots |

`POST /upload?name=<file>` stores the body in the inbox (`--dir`). Name must match `[A-Za-z0-9._-]+` (no slashes), `.png` ≤ 5 MB, `.json` ≤ 200 KB. Uploaded files are served at `/inbox/<name>`; because the inbox is flat, tile paths inside an uploaded `orion.export.json` must be flat file names (e.g. `paint_x.tile.png`), relative to the JSON.

## Data contract

`schema/orion.export.schema.json` documents `orion.export.json` v1; `src/schema.js` is the validator used at runtime and in tests. `lightDir` is a Unity world direction (left-handed); the web negates Z.
