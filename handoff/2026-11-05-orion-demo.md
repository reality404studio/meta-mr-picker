## 0. 한 줄

**앱은 "현실에서 떠 온 재질로 3D 웹 타이틀을 만드는 공간 디자인 툴"이 됐어요.** 화면에서 만든 평범한 글자 ORION 을 꺼내, 현실에서 떠 온 재질 세 가지를 바르고, 다시 웹으로 던져 넣어요. 경쟁 상대는 Spline 이고, 차별점은 현실 재질·움직임 채집이에요 (손으로 자간 늘리기는 차별점이 아님).

## 2. 흐름 v2 (촬영 콘티)

순서는 이 표가 기준. 시간은 3분 미만 안에서 늘려도 됨.

| 시간(초안) | 장면 | 손·도구 | 보이는 것 |
| --- | --- | --- | --- |
| 00~04 | Hook | 맨손, O 톡 | 어두운 책상 위 완성된 ORION (O 윤슬 · R 털 · I 그라데이션 · O 윤슬 · N 그라데이션). 톡하면 파동이 글자 전체로 |
| 04~10 | Before (2배속) | 마우스 | 맥 three.js 에디터에서 트래킹·두께·회전 슬라이더, 재질 프리셋을 넘겨 보다 아쉬움. 헤드셋을 씀 |
| 10~16 | Pull Out | 맨손 검지로 맥북 화면 톡 | 빛과 함께 O→R→I→O→N 차례로 빠져나오며 두께 0→1로 부풀어 호버링. 화면 속 2D 글자는 사라짐 |
| 16~22 | 글자 잡기 | 맨손 핀치 | I 를 위로, N 을 옆으로. 놓으면 살짝 튀며 자리 잡음 |
| 22~27 | 바르기 ① 모아 온 것 | 왼손바닥 뒤집기 → 물감 손 | 포탈 회전판의 윤슬 칩에 손가락 넣었다 빼기 → O 두 개에 대면 윤슬이 일렁임 |
| 27~35 | 바르기 ② 실시간 채집 | 스탬프 도구 집기 | 옷걸이의 흰 털옷 응시 → 펀치 → 핀치 3초 찰칵 → 칩 → R 에 |
| 35~46 | 바르기 ③ 마블링 작업대 | 스포이드 집기 → 맨손 → 물감 손 | 방 안 색 두세 개를 쭉 따서 작업대에 떨굼(저절로 퍼짐) → 맨손으로 휘휘 → 그라데이션 칩 → I·N 에 |
| 46~48 | 감상 | — | 방이 어두워지고(디밍) 세 재질이 돋보임 |
| 48~60 | Throw Back | 맨손으로 글자 전체 쥐고 휙 | 맥북 화면으로 빨려 들어가, 맥 웹에서 같은 재질의 ORION 히어로 회전. 로더 코드 한 줄 + GLB 다운로드 버튼 |

촬영 순서: Before → Pull Out → 글자 잡기 → 바르기 ①②③ → Throw Back → 마지막에 Hook.

## 3. 손 동작 지도 (D6~D8 의 세부, 에이전트 제안)

손 색을 바꾸는 별도 동작은 없어요. 손에 뭐가 있느냐로 색이 정해져요.

| 손 상태 (표시) | 되는 법 | 할 수 있는 일 | 못 하는 일 |
| --- | --- | --- | --- |
| 맨손 (흰 제도선 #F0EEE6) | 기본. 도구를 내려놓거나 포탈 우물에 씻으면 돌아옴 | 맥북 화면 톡, 글자 핀치로 잡아 이동, O 톡(파동), 던지기, 작업대 휘젓기 | 칠하기, 채집 |
| 물감 손 (손끝이 그 칩 색) | 포탈 회전판·작업대 칩에 손가락 넣었다 빼기 | 글자에 대면 버킷 채우기 | 글자 잡기 |
| 스탬프 손 (코발트 #2559B4) | 책상 위 스탬프 도구를 오른손 핀치로 집기 | 영상 텍스처 채집: 시선 펀치(+왼손 ±10cm), 핀치 3초 유지 = 찰칵, 찰칵↔루프 전환 | 글자 잡기, 칠하기 |
| 스포이드 손 (끝이 마지막으로 딴 색) | 책상 위 스포이드를 오른손 핀치로 집기 | 시선 끝 조준점 + 핀치 한 번 = 즉시 색 따기(3초 없음). 작업대 위에서 핀치 = 방울 떨구기 | 글자 잡기, 칠하기 |
| 항상 | 왼손바닥 위로 뒤집기 | 포탈 열기, 테두리 쓸기, 우물에 씻기 | — |

이 구조로 풀리는 겹침: 핀치 네 가지(펀치 조정·모드 토글·찰칵·글자 잡기)는 손 상태로 나뉘고, 손끝 톡 세 가지(화면 톡·O 톡·칠하기)는 손끝 물감 유무와 화면 사각형 안인지로 나뉨.

## 6. 확인 1순위 (리스크)

1. **패스스루 녹화에서 맥북 화면이 읽히는지** — 안 읽히면 맥 화면을 따로 녹화해 편집에서 합성
2. **가까운 물체 크롭** — 지금 `CatchSettings.sceneDistance` 3m 가정. 50cm 앞 털옷을 뜨면 펀치 칸과 담기는 칸이 어긋날 수 있음. 시선 레이가 실제로 닿는 거리를 쓰는 방식 검토
3. **Android cleartext** — `ws://`·`http://` 는 기본 차단. Player Settings 에서 HTTP 허용. 맥 Node 첫 실행 방화벽 창
4. **두 렌더러의 룩 차이** — Unity(HLSL)와 웹(GLSL)에서 같은 셰이더를 두 번 구현. 같은 칩 PNG 로 나란히 비교하는 검증 필요
5. **성능** — 글자 5개 × 트라이플래너 + 플립북 + 디밍 + HUD + 작업대 핑퐁, A3 합격선(60fps, 5초 구간 드롭 ≤3)
6. **흰 털 대비** — 안 칠한 클레이 색과 흰 털이 비슷해 보일 수 있음. 옆빛 조명 + 필요하면 클레이 한 단계 어둡게
7. **Meta VR Start 회원 여부** — 아니면 즉시 신청 (신청 페이지 오류 포럼 글 있음)
