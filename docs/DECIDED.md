## 2026-11-03 · [공통] 검증은 별도 CI 서버가 아니라 Unity 빌드 훅 게이트 + 빌드 ID로 한다

> "빌드 아이디 관리도 중요한거 같고요" / "네 좋아요."

- 게이트: `IPreprocessBuildWithReport` 에디터 스크립트(`unity/shared/BuildGate/`). 검사 실패 = 빌드 실패
- 빌드 ID: git 짧은 해시 + 시각을 빌드에 박고 앱 첫 로그에 출력. logcat 의 ID가 맞아야 "기기에 새 버전"으로 인정
- 에이전트는 빌드를 부탁하기 전에 같은 검사를 사전 점검 스크립트로 먼저 돌린다
- 실기 검증 하위 과업은 빌드 ID가 찍힌 logcat 발췌 + 스크린샷을 첨부해야 `done`
- Codex 리뷰는 게이트에 넣지 않는다. 큰 덩어리(셀 셰이더 등)에서만 수동으로
